# Wortbilder im ChatGPT-Chat malen

So geht's:
1. **Einen neuen Chat öffnen und alle Bögen im selben Chat malen.** So bleibt der Stil gleich.
2. Den ersten Prompt (Bogen 1) einfügen. Gefällt dir das Bild, die weiteren Prompts nacheinander einfügen.
   Ab Bogen 2 steht im Prompt, dass ChatGPT den Stil des ersten Bogens übernehmen soll.
3. Jedes Bild herunterladen und genau mit dem angegebenen Dateinamen speichern, in `bilder-gemalt/boegen/`
   (gleicher Ordner wie beim Skript, z. B. `tiere-1.png` oder `.jpg`).
4. Kommt ein Bild mit falscher Reihenfolge oder einem fehlenden Motiv: einfach den Prompt nochmal schicken oder Claude Bescheid geben.
5. Wenn ChatGPT ein Limit meldet: später im selben Chat weitermachen.

Es sind 22 Bögen. Bögen mit Dateiname, die schon im Ordner liegen, kannst du überspringen.
